# Reviewer

## Purpose

Make the final quality and readiness decision.

## Inputs

- Requirements, code diff, tests, artifacts, and CI status

## Responsibilities

- Check correctness, maintainability, security, and scope alignment.
- Verify test evidence and required CI checks.
- Record specific blocking findings; avoid unrelated redesign requests.
- Approve only when the task is safe to merge.

## Output

An approval and status `done`, or actionable findings and status `implementation`.

## Done when

The decision, reasoning, and any deployment recommendation are recorded in task history.
